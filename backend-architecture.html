Reglas de Negocio Implementadas

Borrado Lógico & Cascada (Soft Delete)

Nunca borramos usuarios físicamente para proteger la reportería. Actualizamos isActive: false.

  • Si es Estudiante: Se desinscribe automáticamente de todas sus clases, liberando sus cupos al instante.
  • Si es Profesor: Sus clases futuras pasan a estado CANCELLED de forma automática.

Auditoría Doble de Cupos

Las clases (Classes) manejan dos contadores diferentes para soportar el módulo de reportería del Administrador:

  • enrolledCount: Contador en vivo. Sube al inscribirse, baja al cancelar. Determina si la clase está llena.
  • historicalEnrolledCount: Solo sube en inscripciones nuevas. Nunca baja. Ideal para métricas históricas de interés.

Seguridad Auth & Redis Blacklist

Sistema de tokens de doble vida (Access 15m + Refresh 7d) para máxima seguridad móvil.

  • Las contraseñas siempre se encriptan con Bcrypt.
  • Al hacer Logout, los JWT activos se envían a Redis. El sistema los rechaza inmediatamente aunque sigan vigentes.

Reciclaje de Inscripciones

Evitamos el error E11000 duplicate key de Mongo gracias al reciclaje inteligente.

  • Si un alumno cancela, su estado pasa a CANCELLED.
  • Si vuelve a matricularse, el backend recicla ese documento, lo pasa a ACTIVE y reajusta los contadores sin duplicar data.

Módulos de la API

Módulo: Users (Usuarios)

Gestión de estudiantes, profesores y admins. El Administrador tiene control total.

POST /users Crea perfil y encripta password.
PATCH /users/:id Actualiza perfil/password de forma segura.
DELETE /users/:id Soft delete + Cascada (Libera cupos).
Módulo: Classes (Clases y Materias)

Gestión de cursos. Los administradores pueden forzar asignaciones con teacherId.

POST /classes Crea clase (valida fechas ISO8601).
GET /classes/subjects Lista de materias únicas registradas.
POST /classes/sync-enrollments Recalcula y repara cupos (Admin).
Módulo: Enrollments (Inscripciones)

El corazón transaccional del sistema. Diseñado tanto para autoservicio (estudiantes) como control (admin).

POST /enrollments Inscribe tomando ID del Token (Estudiante) o del Body (Admin). Sube contadores.
DELETE /enrollments/:id Cancela registro, libera 1 cupo vivo.
GET /enrollments [Reportería] Devuelve toda la trazabilidad histórica cruzada para gráficas.
